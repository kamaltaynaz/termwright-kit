# Examples

Short, generic illustrations written fresh for this kit. **They are examples of shape, not a working tool.** Every value is a placeholder: `canvas.example.edu`, `COURSE_ID`, `YOUR_TOKEN`. Ask your agent to adapt the idea to your set-up, not to copy the text.

| File | What it shows |
|---|---|
| `canvas_get_paginated.py` | A read-only Canvas call that follows paging, reads the token from the environment, and backs off on throttling |
| `config.example.yaml` | The shape of a configuration file with placeholders and safety limits |
| `dry-run-report.md` | What a plan summary and a dry-run report can look like |
| `notification.md` | A change-alert message that carries counts and course numbers, not people |
| `test_fake_canvas_stub.py` | A tiny stateful stand-in for Canvas with fault injection, and two tests that use it |
